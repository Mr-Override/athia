Our Philosophy

Athia is built around nine founding principles that put users first.

User Sovereignty

You own and control your computer. No corporation, no cloud provider — you.

Security First

Security is a foundational architectural requirement, not an afterthought.

Open Source

Development, documentation, and decision-making are transparent.

Offline First

The OS remains fully functional without internet connectivity.

Transparency

Every line of code and design decision is visible and discussable.

Community Ownership

Governed transparently and developed collaboratively by the community.

Independent Architecture

Athia has its own microkernel. It is not based on Linux or any existing operating system.
