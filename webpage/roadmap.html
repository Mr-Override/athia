Roadmap

Six phases from bootable kernel foundation to daily-driver quality. All milestones are planned.

No fixed timeline has been established. Development velocity depends on community participation and available resources.

Phase 1: Genesis

Planned

Bootable kernel foundation — a minimal kernel that can boot on x86_64 hardware.

Kernel skeleton

Entry point, GDT/IDT setup, kernel memory layout. Measurable: kernel loads in QEMU.

Memory management

Physical allocator, virtual memory, kernel heap. Measurable: allocate and free without corruption.

Basic hardware abstraction

Serial output, timer interrupts. Measurable: print to serial console.

Phase 2: Core

Planned

Kernel functionality and process isolation — a functional microkernel with IPC and scheduling.

Process management

Process creation, isolated address spaces, capability system.

Inter-Process Communication

Message passing, capability-based routing, sync and async patterns.

Scheduler

Priority-based preemptive scheduling with context switching.

Phase 3: Systems

Planned

Essential hardware and system services — filesystem, networking, devices, and graphics.

Filesystem service

Basic filesystem with file read/write via IPC.

Device service

Keyboard and mouse input delivered to user-space.

Graphics service

Framebuffer output and display protocol foundation.

Phase 4: Desktop

Planned

Graphical environment — window management, theming, and user interaction.

Window manager

Window creation, resizing, movement, and stacking.

Athia Shell

Desktop panel, application launcher, and system tray.

Appearance Engine

Theme system with Midnight, Daylight, Monochrome, and Aurora.

Traffic Control

Application search, file search, and system settings access.

Phase 5: Ecosystem

Planned

Package management, applications, and developer tools.

Athia Packages

Package format, repository, installation, and update.

Athia SDK

Application API framework and UI toolkit.

Athia Studio

IDE with editing, building, and debugging.

Phase 6: Stable

Planned

Daily-driver quality — stable, secure, and usable as a primary operating system.

Stability

Extended stability testing without crashes.

Security hardening

Security audit and Athia Sentinel.

Community readiness

Community can independently contribute, review, and release updates.

Track Progress

Progress on each milestone will be tracked in the project's issue tracker. See ROADMAP.md for detailed milestones.
