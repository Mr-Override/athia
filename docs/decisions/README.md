## Status

All ADRs have **Proposed** status. They have not been formally approved. The ADRs may be updated as development progresses and community feedback is incorporated.

## ADR Format

Each ADR contains:

- **Title** — Short description of the decision
- **Status** — Current status (Proposed, Accepted, Deprecated, etc.)
- **Context** — The problem or situation that led to the decision
- **Decision** — The decision that was made
- **Alternatives considered** — Other options that were evaluated
- **Consequences** — The outcomes of the decision
- **Open questions** — Questions that remain unresolved
