# Joining Athia

Welcome to Athia! This document explains how to join the community and start contributing.

## What is Athia?

Athia is an independent, open-source operating system being built from the ground up in Rust. It has its own microkernel, system services, desktop environment, and application framework. It is not based on Linux or any other existing operating system.

For more about the project, see [README.md](../../README.md) and [ATHIA_MANIFESTO.md](../../ATHIA_MANIFESTO.md).

## How to Get Started

### 1. Read the Documentation

Start by reading the project documentation:

- **[README.md](../../README.md)** — Project overview
- **[ATHIA_MANIFESTO.md](../../ATHIA_MANIFESTO.md)** — Project philosophy
- **[ARCHITECTURE.md](../../ARCHITECTURE.md)** — System architecture
- **[ROADMAP.md](../../ROADMAP.md)** — Development roadmap
- **[CONTRIBUTING.md](../../CONTRIBUTING.md)** — Contributing guidelines

### 2. Choose How to Contribute

You don't need to be a systems programmer to contribute. Here are some ways to help:

- **Documentation** — Write, edit, and improve project documentation
- **Design** — Contribute to visual design, UX design, and design system
- **Architecture** — Discuss and refine architectural decisions
- **Testing** — Design test strategies and validate implementations
- **Community** — Answer questions and help new contributors
- **Rust development** — Write Rust code for kernel, services, or desktop

### 3. Join the Conversation

- **Issues** — Open issues for bug reports, feature requests, and questions
- **Pull requests** — Submit pull requests for code and documentation changes
- **Architecture discussions** — Participate in ADR discussions in [docs/decisions/](../decisions/)

### 4. Make Your First Contribution

- Look for issues labeled `good first issue` or `documentation`
- Start with small, focused changes
- Follow the contributing guidelines
- Ask for help if you're unsure
