Community

Athia is built by the community, for the community. Join in on the fun.

Our Philosophy

Athia is a community-driven project. No single entity owns or controls it. Governance is transparent, inclusive, and accountable to the community that builds and uses the software.

We believe the best tools are built by the people who use them. If you care about user sovereignty, security, and transparency, we want you to join us.

Ways to Contribute

You don't need to be a systems programmer. Every contribution matters:

  • Documentation — Write, edit, and improve project documentation
  • Design — Visual design, UX design, and design system contributions
  • Architecture — Discuss and refine architectural decisions
  • Testing — Design test strategies and validate implementations
  • Community — Answer questions and help new contributors
  • Rust development — Write Rust code for kernel, services, or desktop

How to Participate

  1. Read the documentation — Start with README.md and the manifesto
  2. Join the conversation — Open issues, discuss architecture, review pull requests
  3. Make your first contribution — Start small: fix a typo, improve documentation, propose an idea
  4. Be respectful — Follow our Code of Conduct

Code of Conduct

We follow the Contributor Covenant Code of Conduct, version 2.1. We are committed to providing a welcoming and inclusive community for everyone.
