Roadmap

Six phases from bootable kernel foundation to daily-driver quality. All milestones are planned.

No fixed timeline. Velocity depends on community participation.

🌱

Phase 1: Genesis

Planned

Bootable kernel foundation — minimal kernel that boots on x86_64.

Kernel skeleton

Entry point, GDT/IDT, memory layout. Kernel loads in QEMU.

Memory management

Physical allocator, virtual memory, kernel heap.

Hardware abstraction

Serial output, timer interrupts.

⚙️

Phase 2: Core

Planned

Functional microkernel with IPC and scheduling.

Process management

Isolated address spaces, capability system.

IPC

Message passing, capability-based routing.

Scheduler

Priority-based preemptive with context switching.

🔧

Phase 3: Systems

Planned

Essential hardware and system services.

Filesystem

File read/write via IPC.

Devices

Keyboard and mouse to user-space.

Graphics

Framebuffer output, display protocol.

🖥️

Phase 4: Desktop

Planned

Graphical environment with window management and theming.

Window manager

Window creation, resizing, stacking.

Athia Shell

Panel, launcher, system tray.

Appearance Engine

Midnight, Daylight, Monochrome, Aurora themes.

Traffic Control

App search, file search, settings.

📦

Phase 5: Ecosystem

Planned

Package management, applications, and developer tools.

Athia Packages

Package format, repository, updates.

Athia SDK

App API framework and UI toolkit.

Athia Studio

IDE with editing, building, debugging.

✅

Phase 6: Stable

Planned

Daily-driver quality — stable, secure, and usable as a primary OS.

Stability

Extended testing without crashes.

Security

Audit and Athia Sentinel.

Community readiness

Independent contribution, review, and releases.

Track Progress

Progress on each milestone will be tracked in the project's issue tracker. See ROADMAP.md for detailed milestones.
