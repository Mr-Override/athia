Contributing

A practical guide to contributing to Athia — regardless of your experience level.

You Don't Need to Be a Systems Programmer

Kernel development is only one part. Documentation, design, testing, architecture discussion, and community building are all essential.

📝

Documentation

Improve clarity, write new docs, create diagrams, review for consistency.

🎨

Design

Desktop UX, design tokens, themes, and design documents.

🦀

Rust Code

Safe idioms, documented APIs, proper error handling, tests.

🧪

Testing

Test strategies, validate against designs, report bugs clearly.

Pull Request Workflow

1

Describe the change

Explain what you're changing and why.

2

Reference issues

Link to relevant discussions.

3

Follow conventions

Match existing style and structure.

4

Keep it focused

One PR per coherent change.

5

Be responsive

Respond to review feedback.
