# Architecture Documentation

This directory contains detailed architectural documentation for the Athia operating system.

## Documents

- **[kernel.md](kernel.md)** — Overview of the Athia kernel design and responsibilities.
- **[microkernel.md](microkernel.md)** — Detailed microkernel architecture, including memory management, scheduling, and hardware abstraction.
- **[desktop.md](desktop.md)** — Athia Desktop environment architecture, including the shell, window manager, and Appearance Engine.
- **[graphics.md](graphics.md)** — Graphics subsystem architecture, including the display server, compositor, and Athia Display Protocol.
- **[security.md](security.md)** — Security architecture, including capability-based security, process isolation, and sandboxing.
- **[ipc.md](ipc.md)** — Inter-Process Communication architecture, including message passing, capability-based routing, and type safety.

## Status

All documents describe **proposed** designs. No components have been implemented. The architecture may evolve as development progresses.
