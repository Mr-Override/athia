# Design Documentation

This directory contains design documents for the Athia operating system, covering the desktop environment, appearance engine, window manager, display server, extension system, and design principles.

## Documents

- **[desktop-design.md](desktop-design.md)** — Detailed design of the Athia Desktop environment, including visual identity, layout, and user interaction.
- **[appearance-engine.md](appearance-engine.md)** — Design of the Appearance Engine, including themes, design tokens, and customization.
- **[window-manager.md](window-manager.md)** — Design of the modular window manager, including tiling, floating, and hybrid modes.
- **[display-server.md](display-server.md)** — Design of the display server and Athia Display Protocol (ADP).
- **[extension-system.md](extension-system.md)** — Design of the extension system, including sandboxing and WebAssembly/WASI support.
- **[design-principles.md](design-principles.md)** — Core design principles that guide all Athia design decisions.

## Status

All documents describe **proposed** designs. No components have been implemented. The design may evolve as development progresses and community feedback is incorporated.
